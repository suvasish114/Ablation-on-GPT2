# Ablation on GPT2 Model

This study is done for partial fullfillment of course requirement at IIT Gandhinagar, in the department of Cognitive Science under [Prof. Vaibhav Tripathi](https://www.vaibhavtripathi.com/). This study perform some ablation study on GPT-2 Models. Due to policy reason the experimental results and detail report is not made public. To know more informaton contact me at [suvasish114.github.io](https://suvasish114.github.io/).

For reproducibility add the below variables in your local environment and execute. I would suggest adding a `
.env` file in your local repo and execute the driving code.
```sh
MODEL_CARD="openai-community/gpt2"
MODEL_PATH="models/gpt2"
# DATA_CARD="mindchain/wikitext2"
DATA_CARD="Salesforce/wikitext"
DATA_PATH="dataset/wikitext2"
```
